# Payment Links APIs

Source: https://razorpay.com/docs/api/payments/payment-links/

Payment Links are URLs that you can send to customers through SMS and email to collect payments from them. Customers click the URL, which opens the payment request page, and complete the payment using any of the available payment methods. You can create, fetch, edit, or cancel Payment Links using APIs or from the Dashboard.

## Endpoints (12 total, per this index page)

1. Create a Standard Payment Link — `POST`
2. Fetch All Standard Payment Links — `GET`
3. Fetch a Standard Payment Link With ID — `GET`
4. Send or Resend Notifications — `POST`
5. Update a Standard Payment Link — `PATCH`
6. Cancel a Standard Payment Link — `POST`
7. Implement Thematic Changes on Checkout — `POST`
8. Change Business Name — `POST`
9. Customise Payment Methods (Options and Method Parameters) — `POST`
10. Customise Payment Methods (Options and Config Parameters) — `POST`
11. Rename Labels in the Checkout Section — `POST`
12. Rename Labels in Payment Details Section — `POST`
