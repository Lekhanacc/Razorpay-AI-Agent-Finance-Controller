# About Payment Links

Source: https://razorpay.com/docs/payments/payment-links/
(Server returned regional variant: https://razorpay.com/docs/us/payments/payment-links)

Razorpay Payment Links let you accept payments without a website or app.

Generate a unique link from the Dashboard or via APIs and share it with customers via email, SMS, or social media. Customers can use these links to pay securely and easily.

You can manage all Payment Links directly from the Dashboard — create, cancel, duplicate, search, or update them. You can also get instant notifications by subscribing to Webhook events. Most of these actions can also be performed using APIs.

## Advantages

- **Create-to-Collect in a matter of minutes**: Create Payment Links easily with a few clicks and share them with customers.
- **Automatic sharing of link**: The customers receive a Payment Link on SMS or email using which they can quickly pay.
- **Set expiry date**: Set due dates for Payment Links after which the links expire.
- **Partial payments**: Allow customers to make partial payments. You can decide the first installment amount to be paid by customers in case of partial payments.
- **Set reminders**: Send automated SMS to customers to remind them about outstanding payments.
- **Easy integration using APIs**: Seamlessly integrate Payment Links with your systems using APIs.

## Supported Payment Methods (per this page)

Online payment via cards is listed on this page as a supported method. (Note: other Razorpay pages describe additional methods such as UPI/netbanking for Payment Links depending on region/account configuration — this page specifically only enumerates card payments.)

## Get Started

Requires a Razorpay account. Log in to the Dashboard and select Payment Links.

## Integration

Payment Links can be integrated with existing order management/billing systems via the Dashboard or APIs — e.g., a Payment Link can be created automatically as soon as an order is created in an external order management system.
